# Smart Tax Expertss – Service Page (React)

    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build in /dist

Files
- src/App.jsx          page markup as JSX + sticky header with mobile menu + scroll-reveal
- src/usePageData.js   all state, content arrays and handlers (hook)
- src/App.css          original styles + responsive breakpoints
- index.html           Google Fonts (Inter, Bricolage Grotesque, DM Mono)

Breakpoints: >=1700 large monitor, <=1100 small laptop, <=900 tablet (hamburger menu),
<=640 phone (full-width buttons), <=480 / <=360 small phones.
